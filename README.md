# Site Jastelo Construções e Empreendimentos

Primeira versão do novo site institucional e comercial da Jastelo.

## Visualizar

Abra `index.html` no navegador ou execute um servidor local na pasta.

## Antes de publicar

- Confirmar telefone, e-mail, redes sociais e endereço.
- Confirmar valores, áreas e disponibilidade dos imóveis.
- Substituir ou ampliar as galerias com as fotos finais de cada casa.
- Conectar o formulário a uma ferramenta de atendimento/CRM, se desejado.
